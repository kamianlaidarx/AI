# AILive 完整使用流程

## 重要说明

AILive 包含两个独立的程序：
1. **Web管理面板** - 用于配置AI、人格和微信参数
2. **微信机器人** - 实际运行的机器人程序，监听和回复微信消息

**这两个程序需要分别启动！**

---

## 完整使用流程

### 第一步：配置参数（使用Web管理面板）

1. **启动Web管理面板**
   ```
   方式一：双击 start_web_panel.bat
   方式二：命令行运行
   cd F:\项目\AILive
   venv\Scripts\activate
   python src\web\app.py
   ```

2. **在浏览器中打开** http://127.0.0.1:5000

3. **配置AI参数**
   - 选择AI提供商：豆包
   - 填写模型ID：ep-20251226192412-8kff2
   - 填写豆包API密钥
   - 点击"测试连接"确认API可用
   - 点击"保存配置"

4. **配置人格参数**
   - 填写AI女友的基本信息
   - 设置性格特征和说话风格
   - 点击"保存配置"

5. **配置微信参数**
   - 填写微信路径：C:\Program Files\Tencent\Weixin
   - 设置自动回复参数
   - 配置黑白名单（可选）
   - 点击"保存配置"

6. **关闭Web管理面板**
   - 在命令行窗口按 Ctrl+C 停止
   - 或直接关闭窗口

### 第二步：启动微信机器人

1. **确保微信已登录**
   - 打开微信客户端（版本 3.9.10）
   - 确保已登录账号

2. **启动机器人**
   ```
   方式一：双击 start_bot.bat
   方式二：命令行运行
   cd F:\项目\AILive
   venv\Scripts\activate
   python src\main.py
   ```

3. **查看启动日志**
   - 看到 "机器人已启动，开始监听消息..." 表示成功
   - 如果出现错误，检查日志文件：logs/ailive.log

4. **测试机器人**
   - 用另一个微信账号给你发消息
   - 或打开一个聊天窗口（wxauto只能监听当前打开的窗口）
   - 机器人会自动回复

5. **停止机器人**
   - 在命令行窗口按 Ctrl+C
   - 或直接关闭窗口

---

## 重要注意事项

### 关于wxauto（微信3.9.10）

**wxauto的限制：**
- ✅ 只能读取**当前打开的聊天窗口**的消息
- ✅ 需要保持聊天窗口在前台或最小化（不能切换到其他聊天）
- ❌ 无法监听所有聊天窗口
- ❌ 无法监听群聊（除非打开群聊窗口）

**使用建议：**
1. 启动机器人后，打开要监听的聊天窗口
2. 保持该窗口打开（可以最小化微信，但不要切换聊天）
3. 对方发送消息后，机器人会自动回复

### 配置修改

如果需要修改配置：
1. 停止机器人（Ctrl+C）
2. 启动Web管理面板
3. 修改配置并保存
4. 关闭Web管理面板
5. 重新启动机器人

## 常见问题排查

### 问题1：机器人启动后没有反应

**可能原因：**
- 微信未登录 → 确保微信已打开并登录
- 没有打开聊天窗口 → 打开要监听的聊天窗口
- API密钥错误 → 检查Web管理面板中的API配置
- 微信版本不对 → 确保使用微信 3.9.10

**排查步骤：**
1. 查看日志文件：logs/ailive.log
2. 检查是否有错误信息
3. 确认配置文件：config/config.yaml 和 config/.env

### 问题2：提示"微信未登录或未运行"

**解决方法：**
1. 确保微信客户端已打开
2. 确保已登录账号
3. 检查微信路径配置是否正确
4. 尝试重启微信

### 问题3：API调用失败

**解决方法：**
1. 在Web管理面板中点击"测试连接"
2. 检查API密钥是否正确
3. 检查网络连接
4. 查看豆包API控制台是否有额度

### 问题4：收到消息但不回复

**可能原因：**
- 发送者在黑名单中
- 消息包含过滤关键词
- 白名单不为空但发送者不在白名单中
- AI生成回复失败

**排查步骤：**
1. 查看日志：logs/ailive.log
2. 检查过滤器配置：config/config.yaml
3. 测试AI是否正常：python src/main.py --mode interactive

## 测试模式

如果想测试AI回复而不连接微信：

```bash
cd F:\项目\AILive
venv\Scripts\activate
python src\main.py --mode interactive
```

在交互模式下：
- 直接输入消息测试AI回复
- 输入 quit 退出
- 不需要微信客户端

## 日志查看

日志文件位置：`logs/ailive.log`

日志级别（在config.yaml中配置）：
- DEBUG：详细调试信息
- INFO：一般信息
- WARNING：警告信息
- ERROR：错误信息
