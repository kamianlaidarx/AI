# ✅ 主动对话功能已实现！

## 功能概述

现在AI女友不仅会回复你的消息，还会在你长时间没发消息时**主动找你聊天**，就像真正的女朋友一样！

## 实现的功能

### 1. 智能时机判断

机器人会在以下条件**全部满足**时主动发起对话：
- ✅ 超过设定的闲置时间（默认1小时）
- ✅ 有之前的对话历史（至少2条消息）
- ✅ 今天主动次数未超过上限（默认3次）
- ✅ 距离上次主动聊天至少30分钟
- ✅ 30%的随机概率（避免太机械）

### 2. 基于上下文的消息生成

**智能生成模式：**
- 提取最近对话的话题
- 基于话题和上下文，AI生成自然的问候
- 体现关心和延续话题

**备选预设消息：**
- "好久没聊天了，想你了呀~"
- "在干嘛呢？"
- "突然想起你了~"
- "有没有想我呀？"
- "最近怎么样？"

### 3. 频率控制

- 每天最多主动3次（可配置）
- 两次主动至少间隔30分钟
- 每5分钟检查一次是否需要主动
- 避免打扰用户

## 配置说明

在 `config/config.yaml` 中：

```yaml
proactive_chat:
  enabled: true              # 是否启用
  idle_time: 3600            # 闲置1小时后主动
  min_interval: 1800         # 最小间隔30分钟
  max_daily_proactive: 3     # 每天最多3次
```

### 快速调整

**更频繁（测试用）：**
```yaml
proactive_chat:
  enabled: true
  idle_time: 60              # 1分钟
  min_interval: 30           # 30秒
  max_daily_proactive: 10
```

**较少打扰：**
```yaml
proactive_chat:
  enabled: true
  idle_time: 7200            # 2小时
  min_interval: 3600         # 1小时
  max_daily_proactive: 2
```

**完全禁用：**
```yaml
proactive_chat:
  enabled: false
```

## 技术实现

### 核心文件

1. **src/core/proactive_chat.py**
   - ProactiveChatManager 类
   - 管理主动对话逻辑
   - 时间跟踪和频率控制

2. **src/core/message_handler.py**
   - 集成主动对话管理器
   - 更新最后消息时间
   - 检查和发送主动消息

3. **src/main.py**
   - 主循环中每5分钟检查一次
   - 调用 check_and_send_proactive_messages()

### 工作流程

```
主循环（每2秒）
    ↓
每5分钟触发检查
    ↓
遍历所有用户
    ↓
检查是否满足主动条件
    ↓
生成主动消息
    ↓
发送消息
    ↓
记录时间和次数
```

## 注意事项

### 1. API费用

- 每次主动消息都会调用AI API
- 建议合理设置 `max_daily_proactive`
- 监控API使用量

### 2. 用户体验

- 不要设置太频繁
- 建议 `idle_time` 至少30分钟
- 建议 `max_daily_proactive` 不超过5次

### 3. 测试建议

**首次测试：**
```yaml
idle_time: 60              # 1分钟（快速测试）
min_interval: 30           # 30秒
max_daily_proactive: 5
```

**测试完成后改回：**
```yaml
idle_time: 3600            # 1小时
min_interval: 1800         # 30分钟
max_daily_proactive: 3
```

## 故障排查

**Q: 没有收到主动消息？**
A: 检查：
1. `enabled` 是否为 `true`
2. 是否有对话历史
3. 是否超过 `idle_time`
4. 今天是否已达到上限
5. 查看日志文件

**Q: 主动消息太频繁？**
A: 调整配置：
- 增大 `idle_time`
- 减少 `max_daily_proactive`
- 增大 `min_interval`

**Q: 主动消息内容不自然？**
A:
- 多聊几次，让AI学习你的风格
- 调整人格配置
- AI生成失败时会使用预设消息
