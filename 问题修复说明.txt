# 问题已修复 - 微信被关闭的问题

## 问题原因

之前的代码在检测不到微信版本时，会默认使用 WeChatFerry。
WeChatFerry 会尝试注入微信进程，导致微信3.9.10被强制关闭。

## 解决方案

已修改代码，现在：
1. **优先使用 wxauto**（适用于微信3.9）
2. 只有在微信4.0+时才使用 WeChatFerry
3. 避免了微信被关闭的问题

## 现在可以正常使用了

### 启动步骤：

1. **确保微信已登录**（版本3.9.10）

2. **启动机器人**
   ```
   双击 start_bot.bat
   ```

3. **打开聊天窗口**
   - 打开要监听的聊天窗口
   - 保持窗口打开（可以最小化微信）

4. **测试**
   - 让对方发消息
   - 机器人会自动回复

### 重要提示：

**wxauto的工作方式：**
- ✅ 只监听**当前打开的聊天窗口**
- ✅ 需要保持聊天窗口打开
- ❌ 不能切换到其他聊天
- ❌ 不能关闭聊天窗口

**正确使用方法：**
1. 启动机器人
2. 打开要监听的聊天窗口
3. 保持该窗口打开（不要切换）
4. 对方发消息后会自动回复

### 查看日志

如果还有问题，查看日志文件：
```
logs/ailive.log
```

日志会显示：
- 使用的微信库（应该是 wxauto）
- 微信连接状态
- 收到的消息
- AI回复内容

---

## 故障排查

**Q: 还是没有反应？**
A:
1. 确认日志显示"使用 wxauto"
2. 确认聊天窗口已打开
3. 确认微信已登录
4. 查看日志中的错误信息

**Q: 如何确认机器人在运行？**
A: 命令行窗口会显示：
```
机器人已启动，开始监听消息...
```

**Q: 如何停止机器人？**
A: 在命令行窗口按 Ctrl+C
