# 启动Web管理面板

## 方法一：使用Python命令（推荐）

1. 打开命令提示符（CMD）
2. 进入项目目录：
   ```
   cd F:\项目\AILive
   ```

3. 激活虚拟环境：
   ```
   venv\Scripts\activate
   ```

4. 启动Web面板：
   ```
   python src\web\app.py
   ```

5. 在浏览器中访问：http://127.0.0.1:5000

## 方法二：使用启动脚本

双击运行 `start_web_panel.bat` 文件

注意：如果出现编码错误，请使用方法一。

## 停止服务器

在命令提示符窗口中按 `Ctrl+C` 停止服务器

## 常见问题

**Q: 提示 "No module named 'flask'"？**
A: 需要先安装Flask：
```
venv\Scripts\activate
pip install flask flask-cors
```

**Q: 端口5000被占用？**
A: 可以修改 `src\web\app.py` 文件中的端口号（第58行）

**Q: 无法访问管理面板？**
A:
1. 确认服务器已启动（看到 "Running on http://127.0.0.1:5000"）
2. 检查防火墙设置
3. 尝试使用 http://localhost:5000 访问
