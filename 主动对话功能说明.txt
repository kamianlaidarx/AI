# 主动对话功能说明

## ✨ 新功能：AI女友会主动找你聊天！

现在机器人不仅会回复你的消息，还会在你长时间没发消息时主动找你聊天，就像真正的女朋友一样！

## 功能特点

### 1. 智能判断时机

机器人会在以下情况主动发起对话：
- ✅ 超过1小时没有收到你的消息
- ✅ 有之前的对话历史（不会对陌生人主动）
- ✅ 今天主动次数未超过上限（默认3次）
- ✅ 距离上次主动聊天至少30分钟

### 2. 基于上下文的主动消息

机器人会根据你们之前的对话内容，生成自然的主动消息：

**场景1：延续话题**
```
之前聊天:
你: 我今天要去打篮球
AI: 哇，打篮球很酷呀！

1小时后，AI主动:
AI: 打完篮球了吗？累不累呀~
```

**场景2：关心问候**
```
之前聊天:
你: 今天心情不太好
AI: 怎么了呀？发生什么事了吗？

1小时后，AI主动:
AI: 现在心情好点了吗？想你了呀~
```

**场景3：随机问候**
```
AI: 在干嘛呢？
AI: 好久没聊天了，想你了呀~
AI: 突然想起你了~
AI: 有没有想我呀？
```

### 3. 智能频率控制

- 每天最多主动3次（可配置）
- 两次主动聊天至少间隔30分钟
- 30%的随机性，不会太频繁
- 避免打扰用户

## 配置说明

在 `config/config.yaml` 中配置：

```yaml
proactive_chat:
  enabled: true              # 是否启用主动对话
  idle_time: 3600            # 闲置多久后主动（秒），1小时=3600秒
  min_interval: 1800         # 最小间隔（秒），30分钟=1800秒
  max_daily_proactive: 3     # 每天最多主动几次
```

### 参数说明

**enabled（是否启用）**
- `true`：启用主动对话
- `false`：禁用主动对话，只被动回复

**idle_time（闲置时间）**
- 单位：秒
- 推荐值：
  - 1800秒（30分钟）- 比较频繁
  - 3600秒（1小时）- 适中（推荐）
  - 7200秒（2小时）- 较少

**min_interval（最小间隔）**
- 单位：秒
- 推荐值：
  - 1800秒（30分钟）- 推荐
  - 3600秒（1小时）- 较少

**max_daily_proactive（每天最多次数）**
- 推荐值：
  - 2-3次：适中（推荐）
  - 5-10次：较多
  - 1次：较少

## 工作原理

### 检查流程

```
每5分钟检查一次
    ↓
遍历所有聊过天的用户
    ↓
检查是否满足主动条件
    ↓
生成基于上下文的主动消息
    ↓
发送消息
    ↓
记录主动次数和时间
```

### 主动消息生成

1. **提取话题**：从最近5条消息中提取话题
2. **AI生成**：基于话题和上下文，让AI生成自然的问候
3. **备选方案**：如果AI生成失败，使用预设的问候语

## 注意事项

### 1. API费用

- 每次主动消息都会调用AI API
- 建议合理设置 `max_daily_proactive`
- 监控API使用量

### 2. 用户体验

- 不要设置太频繁，避免打扰
- 建议 `idle_time` 至少30分钟
- 建议 `max_daily_proactive` 不超过5次

### 3. 隐私考虑

- 主动消息基于历史对话生成
- 确保对话内容适合主动提及
- 可以随时禁用此功能

## 禁用主动对话

如果不想要主动对话功能，在 `config/config.yaml` 中设置：

```yaml
proactive_chat:
  enabled: false
```

## 常见问题

**Q: 为什么没有收到主动消息？**
A: 检查以下几点：
1. `enabled` 是否为 `true`
2. 是否有对话历史（至少2条消息）
3. 是否超过 `idle_time`
4. 今天是否已达到 `max_daily_proactive`
5. 查看日志文件确认

**Q: 主动消息太频繁怎么办？**
A: 调整配置：
- 增大 `idle_time`（如改为7200秒=2小时）
- 减少 `max_daily_proactive`（如改为1或2）

**Q: 主动消息内容不自然？**
A: 这是AI生成的，可能偶尔不够自然。可以：
- 调整人格配置，让AI更了解你的喜好
- 多聊几次，让AI学习你的对话风格

**Q: 如何完全禁用？**
A: 设置 `enabled: false`
