# 上下文记忆功能说明

## 功能概述

现在机器人具有**持久化上下文记忆**功能，可以记住之前的对话内容。

## 工作原理

### 1. 自动加载历史对话

当用户第一次发消息时：
- 机器人会自动加载该用户的历史对话
- 从上次对话的地方继续
- 不会从零开始

### 2. 自动保存对话

- 每5条消息自动保存一次
- 保存到 `data/conversations/` 目录
- 每个用户一个文件：`用户名_context.json`

### 3. 滑动窗口机制

- 保留最近20条消息（可配置）
- 超过20条会自动删除最旧的
- 保证上下文不会太长，节省API费用

## 配置说明

在 `config/config.yaml` 中：

```yaml
ai:
  max_context_messages: 20  # 保留的最大消息数
```

- 数值越大，记忆越长，但API费用越高
- 推荐值：10-30条

## 使用示例

**第一次对话：**
```
用户: 你好
AI: 你好呀！很高兴认识你~

用户: 我叫小明
AI: 小明你好！记住啦~
```

**关闭机器人，重新启动后：**
```
用户: 你还记得我叫什么吗？
AI: 当然记得！你叫小明呀~
```

## 文件存储

对话历史保存在：
```
data/conversations/
├── 小��_context.json
├── 小红_context.json
└── ...
```

每个文件包含：
- 消息内容
- 角色（user/assistant）
- 时间戳

## 清除历史

如果需要清除某个用户的对话历史：

**方法一：删除文件**
```
删除 data/conversations/用户名_context.json
```

## 注意事项

1. **隐私保护**
   - 对话历史保存在本地
   - 不会上传到云端
   - 注意保护 `data/conversations/` 目录

2. **存储空间**
   - 每个用户的历史文件约几KB到几十KB
   - 定期清理不需要的历史文件

3. **API费用**
   - 上下文越长，每次API调用费用越高
   - 建议根据实际需求调整 `max_context_messages`

## 优势

✅ **连续对话** - 记住之前说过的话
✅ **个性化** - 了解每个用户的特点
✅ **自然交流** - 不需要重复介绍自己
✅ **持久化** - 重启程序不丢失记忆
