### 3. 获取API密钥的详细说明

在README中添加了完整的步骤：

```
第四步：获取豆包API密钥

1. 访问火山引擎控制台：https://console.volcengine.com/ark
2. 注册/登录账号
3. 创建推理接入点（Endpoint）
4. 选择合适的模型（推荐：豆包视觉理解模型）
5. 获取 Endpoint ID（格式：ep-xxxxxx）
6. 创建 API Key
7. 保存这两个信息，后面配置时需要用到
```

### 4. Web管理面板使用说明（适合小白）

**详细步骤：**

1. 启动Web管理面板
2. 在浏览器中打开 http://127.0.0.1:5000
3. 在"AI配置"页面填写：
   - AI提供商：选择"豆包 (Doubao)"
   - 模型/Endpoint ID：填写你的Endpoint ID
   - 豆包 API Key：填写你的API密钥
   - Temperature：0.8（默认值）
   - 点击"测试连接"验证
   - 点击"保存配置"
4. 在"人格配置"页面设置AI女友性格（可选）
5. 在"微信配置"页面设置（可选）
6. 关闭Web管理面板

### 5. 手动配置说明（适合技术用户）

4. （可选）编辑 config/persona.yaml
